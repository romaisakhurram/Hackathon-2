# 🎨 Frontend Engineer Skills & Capabilities

Is file mein `frontend-engineer` agent ki UI aur UX se mutalliq skills define hain.

### Skill: `setup_nextjs_app`
- **Description:** Next.js 16 (App Router) ka folder structure aur boilerplate setup karna.
- **Action:** `app/` directory layouts aur page components initialize karna.

### Skill: `build_responsive_ui`
- **Description:** Tailwind CSS use karke responsive todo dashboard banana.
- **Action:** Mobile-first approach ke saath Task Cards aur Forms design karna.

### Skill: `client_state_management`
- **Description:** React hooks (useState, useEffect) aur Server Components ka balance maintain karna.
- **Action:** Real-time UI updates (Optimistic UI) implement karna jab task add ya complete ho.
