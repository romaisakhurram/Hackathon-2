# 🔐 Integration & Security Skills

Yeh skills `integration-specialist` use karta hai frontend aur backend ko connect karne ke liye.

### Skill: `setup_better_auth`
- **Description:** Better Auth core library aur JWT plugin frontend par install karna.
- **Action:** `auth-client.ts` setup karna aur token storage manage karna.

### Skill: `verify_jwt_middleware`
- **Description:** Backend (FastAPI) par ek middleware banana jo har request ka token check kare.
- **Action:** `PyJWT` use karke `BETTER_AUTH_SECRET` ke saath token decode karna.

### Skill: `secure_api_client`
- **Description:** Ek robust Axios ya Fetch wrapper banana jo har request mein Bearer token bheje.
- **Action:** `/frontend/lib/api.ts` file create karna.
